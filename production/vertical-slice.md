# 垂直切片定义（最小可玩）·《WASTELAND ESCAPE / 废土逃生》

> 阶段：Phase 4 预制作（垂直切片）｜ 作者：程基岩（engineering-lead-3）
> 目的：用最小功能集验证核心循环「**好玩**」（auto-forward + 三轨 + 跳/二段跳/滑 + 单类障碍 + 拾取计分 + 过弯锁中轨 + 结算复活）。
> 配套：production/epics/*（⭐ Story 命中表）、docs/architecture/test-plan.md（S1–S12 烟雾）、architecture.md §6 / ADR-001..005。

---

## 0. 切片目标（一句话）
一条能「自动跑起来、能被躲过、能计分、能过弯、能死、能看广告复活」的最小三轨身后视角跑酷，用来在真实手感下确认 **P1 一指即达 / P2 风险即奖励 / P3 30 秒成长** 三支柱成立，而非堆功能。

---

## 1. 切片范围（IN — 必须可玩）
| 模块 | 切片内含 | 对应 Epic/Story | 验收（玩法层） |
|---|---|---|---|
| 自动前进 | `d += V·dt`，`V=V(d,combo)` 起步 V0=7，封顶 13 | CRL-1/2/3 | 松手也持续前进，速度随距离缓增 |
| 三轨切轨 | lane∈{0,1,2}，左右滑/AD 切轨，平滑插值 | LCS-2/4 | 单指左右滑即切轨，不瞬移 |
| 跳（含二段跳） | 上滑矮跳/按住高跳/空中再上滑二段跳 | LCS-4/5 | 上滑躲地面障，二段跳空中再跳 |
| 滑铲 | 下滑 SLIDE 0.45s，对 Overhead 无敌 | LCS-4/5 | 下滑躲横杆 |
| 单类障碍 | **Blocker（满高 SWITCH-only）** 切轨规避 | OBG-4（仅 Blocker） | 见障碍即必须切到空轨，错切=撞=死 |
| 拾取计分 | 补给（独立池 32）当前轨拾取 +1 连击 +10 分 | OBG-2/6、COM-3/4/6 | 收补给即连击+分增长 |
| 过弯锁中轨 | 1 个最简弯：CORNER 强制中轨 + 锁横向输入 + yaw 视觉旋转；中轨仅 Spike/Overhead | LCS-3/6、OBG-7 | 进弯自动回中轨，弯中仍可跳/滑 |
| 死亡结算 | FATAL_HIT→RESULT，写最佳距离/分数 | CRL-1/4/5、PER-1/3/4 | 撞 Blocker 即死，结算显最佳 |
| 一键重开 | RESULT→COUNTDOWN→RUNNING <2s | CRL-5 | 重开不重载场景，对象池复用 |
| 激励视频复活 | 最简 Web/mock Provider；上限 **3天/1局** | RAD-1/3/4/5/6 | 看广告回 RUNNING（清障+1s 无敌），上限真触发 |
| 基础 HUD | 距离/分数/连击（只读订阅） | CRL-4、HUD | HUD 不持有状态 |
| Web 运行时 | 切后台暂停 / 音频 resume / 480p 兜底 | CRL-6 | tab blur 不「回来即死」 |

> 切片障碍只用 **Blocker 单类** 验证「切轨规避」核心动词；跳/滑用 Blocker 之外的占位低障（或切片临时允许 Blocker + 1 个跳障）以打通跳/滑手感。垂直切片定义允许用最简占位美术（纯色矩形 + 形状编码），不依赖 art-bible 终稿。

## 2. 不在切片内（OUT — 延后）
- **障碍类型**：Spike/Overhead 正式美术、Gap/Moving/Sequence（核心档，OBG-8）。
- **近失分层**：同轨贴脸 +2、急救包（连击星）置于风险轨（CORE，COM-3/6 门控）。
- **倍率曲线全开**：`m_max=5`、流速加成 `k_c`、连击峰值特效（CORE）。
- **跨局里程碑 UI/解锁**：皮肤/称号/特效解锁界面（D4，PER-3 milestones 仅存数据，切片不展示）。
- **多场景/昼夜/速度分段**、动态天气（CORE/延展）。
- **Provider 全量**：TapTap / 微信·抖音小程序 Provider 与 CMP 方案（RAD-2，切片用 mock Web Provider，CONCERN C6）。
- **粒子特效**：ParticlePool 速度线/沙尘（fx）切片可最简或省略；BlobShadow 保留（无实时阴影，ADR-001）。
- **完整 Menu 包装**、音频曲/音效终稿、无障碍模式（自动滑铲/色盲配色，延展档）。
- **异步排行榜 / 后端**（延展，需服务端）。

## 3. 验收「好玩」的判据（Fun Criteria）
> 判据分三类：**可玩门槛（P1）/ 风险回报（P2）/ 成长感（P3）**，每条须有可测信号（单测 or playtest 度量）。

### 3.1 硬性门禁（CI / 单测必须过，对应 test-plan §3）
- [F1] **复活上限强制**：每日第 4 次、本局第 2 次复活请求均被拒（S9/R1/R2）。`test_revive_caps` 红即拒。
- [F2] **可解性**：随机 1000 段至少一轨可通行（S10，`test_solvable`）。
- [F3] **零不可解局**：切片任意生成段「可达轨集合非空」（同 F2）。
- [F4] **一致性红线**：grep 校验模块间仅经 EventBus、Player 不读 InputEvent（control-manifest §B/D）。

### 3.2 P1 一指即达（新手门槛）
- [P1-1] 新玩家（无教程）首次进入 **30s 内不死** 比例 ≥ 70%（playtest 抽样 10 人）。
- [P1-2] 切轨/跳/滑输入响应延迟 < 80ms（从手势到玩家 x/y 开始变化）。
- [P1-3] 仅「左右滑+上滑+下滑」三手势即可存活（二段跳=空中再上滑，无新手势）。

### 3.3 P2 风险即奖励（贴脸有回报）
- [P2-1] 相邻轨掠过近失 **flank +1** 在 MVP 即触发（S11），玩家收补给/掠过即感知连击增长。
- [P2-2] 真实碰撞=死亡（失误≠死亡）：近失未撞不清零、不致死（S6/S8）。
- [P2-3] 同轨贴脸 +2 路径在 CORE 启用后，playtest 确认「贴脸风险真实存在但未主导」（防 CONCERN 主导策略，需实测近失带宽）。

### 3.4 P3 30 秒成长感
- [P3-1] 单局时长落入 30–90s 目标区间（core-loop §4），死亡→重开 <2s（F 级实测）。
- [P3-2] 距离/分数/连击每帧可见增长（HUD 实时）；最佳记录跨局保留且可见。
- [P3-3] 速度随距离缓增带来「越跑越快」的精通反馈，不掉帧（perf-budget §2：60fps@720p）。

### 3.5 性能 / 平台（R4）
- [R4-1] 720p 稳 60fps（480p 兜底 30fps 下限）；GC 尖刺 <0.5ms；单屏 draw call ≤50。
- [R4-2] 首屏游戏资源 `.pck` <5MB（引擎 `.wasm` 经 CDN 另计，perf-budget §5 口径）。
- [R4-3] Web 切后台暂停物理 tick，回前台无「回来即死」。

### 3.6 「好玩」总判定
> **切片通过 = F1–F4 全绿 + P1-1/P1-2 + P2-1 + P3-1/P3-2 + R4-1 实测达成**。
> 任一硬门禁（F*）不达成 → 切片不通，回对应 Story 修；P2-3 / 同轨贴脸等 CORE 项不 blockage 切片，留 playtest 调参。

## 4. 切片构建顺序（建议）
1. 投影 + 三轨 + 自动前进 + 基础 HUD（能跑、能切轨、能看距离增长）。
2. + 跳/二段跳/滑铲 + 单类 Blocker 障碍 + AABB 碰撞 + 死亡结算（核心循环闭合）。
3. + 拾取池 + flank 近失 +1 连击（P2 可见回报）。
4. + 最简过弯（锁中轨 + yaw）+ 中轨跳/滑障（P1 弯中不致死）。
5. + 存档最佳 + 一键重开 <2s。
6. + mock 复活链路 + 上限 3天/1局（F1 硬门禁）。
7. 跑 test-plan §3 全烟雾套件 + playtest 采样判定 §3.2–3.5。

## 5. 切片对 Epic 的回溯
- 切片命中的 Story 见 `production/epics/README.md` ⭐ 表（CoreRunLoop 4 / LaneCornerSystem 6 / ObstacleGeneration 5 / ComboScoring 5 / ReviveAd 5 / Persistence 5）。
