# 游戏概念文档 · 《WASTELAND ESCAPE / 废土逃生》

> 项目阶段：Phase 1 概念孵化 ｜ 评审强度：lean ｜ 引擎：Godot 4（gl_compatibility / WebGL2 导出）｜ 平台：Web / HTML5 + TapTap + 微信/抖音小程序（H5 容器）
> 概念种子：无限跑酷（endless runner）—— 丧尸末日废土背景下，第三人称追尾视角、三条纵向轨道自动前进，单指滑动切换轨道 / 跳跃 / 滑铲 / 过弯，躲开丧尸与废墟、贴脸收集补给，追求逃生距离与连击。

---

## 1. 一句话概念（High Concept）
一款为**碎片时间网页与小程序玩家**打造的极简丧尸末日跑酷：**2.5D 伪3D 三轨背后视角**（类《神庙逃亡》结构）——玩家在左 / 中 / 右三条纵向轨道之一奔跑，镜头第三人称追尾、赛道向纵深延伸，单指滑动即可切轨 / 跳 / 滑 / 过弯，躲开丧尸群与残骸、贴脸收集补给，不断刷新逃生距离记录——**一指即达上手，风险即奖励精通，30 秒一局的再来一次欲**。

---

## 2. 操作映射（贯穿所有文档的核心契约）
> 全部操作用**单指触屏**或**键盘方向键**即可完成（对应 P1 一指即达）。无新按键 / 新手势，复杂度来自组合与时机。

| 输入 | 动作 | 说明 |
|---|---|---|
| 左右滑动（← / →） | 切换相邻轨道 | 三轨：左(0) / 中(1) / 右(2)，带平滑插值；不可跨轨瞬移 |
| 上滑（↑） | 跳跃 | 短按矮跳 / 长按高跳（按住时长→高度映射）；空中再次上滑 = 二段跳（同一手势时序组合，核心档） |
| 下滑（↓） | 滑铲 | 钻过低矮横障，带短暂无敌帧（仅对低障） |
| 赛道周期性过弯（左 / 右弯） | 转角子状态 | **过弯时锁定中轨、视角旋转、横向输入暂停**，过弯后恢复可切轨（核心档；详见 core-loop §2.6） |

- **P1 保证**：MVP 仅需"左右滑 + 上滑 + 下滑"三个手势即可存活；二段跳 = 空中再次上滑（同一手势的时序组合），**未引入任何新按键 / 新手势**。
- 过弯为**脚本化转角**，玩家无需主动转向输入——横向输入在转角期间被系统暂停，避免误切轨致死，同时强化"被迫专注"的感官张力（Sensation）。

## 3. 末日丧尸主题 / 黄昏夜晚美术基调
- **丧尸末日废土（Zombie Wasteland）**：暗调**黄昏 / 夜晚** + 应急光 / 余烬微光（替代高对比霓虹），让障碍轮廓在高速纵深下清晰可读（可读性优先），同时营造废土流速与紧张逃生的沉浸感。
- **低多边形 / 极简几何（Low-Poly Minimal Geometry）**：面数少、draw call 低，契合 Web/小程序性能预算；抽象造型降低美术产能压力。
- **动态速度线 / 运动残影（Motion Trails & Speed Lines）**：强调"快"与"连击"，强化 Sensation 取向与打击反馈。
- **明快配色 + 强轮廓（High-Legibility Palette）**：障碍用"形状 + 亮度"双编码，色盲友好，不依赖纯色彩区分危险。
- **废土 / 余烬点缀（Subtle Embers / Alert Accents）**：仅作连击高潮 / 收集时的点缀（应急光闪烁、余烬微粒），不喧宾夺主，保持 lean。
- **丧尸末日仅为视觉与叙事包装**：无剧情进度 / 对话系统，不污染核心支柱（见 §9 支柱漂移红线）。

---

## 4. 变现：激励视频（复活 + 可选额外奖励）
- 采用**激励视频（rewarded video）**：**MVP 无任何广告**；**核心档**引入三处广告钩子（频率上限防滥用，Web 走 H5 广告 SDK / 发行平台，由工程侧评估接入）：
  1. **死亡复活 `revive`**：结算时看广告复活续跑（核心变现主钩子）。
  2. **结算翻倍 `double`**：看广告使本局补给翻倍。
  3. **里程碑额外奖励 `milestone`**：跨局里程碑触发时看广告领额外奖励。
- 皮肤等仍可用累计补给解锁，**无强制付费**。每日激励视频上限与平台政策对齐（见 core-loop §6.1，`rvDailyCap=3`）。

## 5. 平台
- **Web / HTML5**：即点即玩，引擎 `.wasm` 经 CDN 缓存，游戏资源 `.pck < 5MB`。
- **TapTap**：移动端发行与社区。
- **微信 / 抖音小程序（H5 容器）**：H5 容器承载同一 Web 构建，复用激励视频走平台广告 SDK。
- 性能目标统一：**60fps@720p（移动端降级 480p）**，draw calls ≤ 50。

## 6. 范围分层
### MVP（最小可玩 · 验证核心手感）
1. 三轨自动前进 + 左右切轨（平滑插值）+ 跳跃 + 滑铲
2. 一种障碍（如钢筋尖刺 / 丧尸爪）+ 一种收集（补给）
3. 连击与距离计分 HUD
4. 死亡 → 一键重开（本地最佳记录 `localStorage`）
5. 单一场景 / 单一速度曲线 / 无过弯

### 核心（正式上线所需）
1. **过弯转角**（左 / 右弯 segment，锁定中轨 + 视角旋转 + 横向输入暂停）
2. **二段跳**（空中再次上滑）
3. 多障碍类型 + 移动 / 序列障碍 + **近失**事件（贴脸高回报）
4. 连击倍率系统（含贴脸 / 近失奖励）
5. 角色 / 皮肤解锁（补给经济）+ 基础音效与打击感
6. **激励视频钩子**（复活 / 翻倍 / 里程碑，见 §4 与 core-loop §6.1）

### 延展（锦上添花）
1. 每日挑战 / 全球异步排行榜（需后端，谨慎评估）
2. 关卡编辑 / 社区路线分享
3. 极简世界观碎片解锁
4. 皮肤特效 / 粒子升级、BGM 动态混音
5. 无障碍模式（自动滑铲、减速、色盲配色）

## 7. 设计支柱（Pillars）
| # | 支柱（一句话） | 它如何指导决策 |
|---|---|---|
| **P1** | **一指即达的纯粹操作** — 单指也能活，但精通来自动作的组合与时机。 | 任何新机制都不得新增"必须学会才能玩"的输入；复杂度来自排列组合（切轨 + 跳 + 滑 + 过弯的时序），而非新按键。 |
| **P2** | **风险即奖励** — 越贴脸、越贪心，倍率越高；安全路线存在但低效。 | 关卡与计分设计必须让"保守路线"可行但收益低，"贴障碍穿越 / 近失收集"高风险高回报；连击清零威胁驱动玩家维持动作密度，但单次失误不直接致死。 |
| **P3** | **30 秒一局的成长感** — 单局短、重开快、每局都有可见成长。 | 失败惩罚轻、重开零等待；距离、连击、解锁每局可见；难度曲线平滑，避免认知过载与早期劝退。 |

## 8. MDA 分析
### Mechanics（基础机制清单）
- **三轨自动前进**：沿赛道纵深推进，速度随距离 / 连击缓增（封顶，见 core-loop §2.4 速度模型）
- **切轨**：左右滑在左(0)/中(1)/右(2) 三轨间平滑插值切换，不影响前进速度
- **跳跃**：短按矮跳 / 长按高跳（高度由按住时长映射）；空中再次上滑 = 二段跳
- **滑铲**：下蹲穿越低矮横障，带短暂无敌帧（仅对低障）
- **过弯转角**（核心档）：赛道由 segment 组成（left/right/straight）；进入转角锁定中轨、视角旋转、横向输入暂停，过弯后恢复
- **障碍**：静态（钢筋尖刺 / 断梁 / 横杆）、移动（游荡丧尸 / 翻倒车辆）、序列（丧尸潮 / 连环坍塌）
- **收集物**：补给 / 急救包（经济）、连击星（维持倍率）
- **连击系统**：连续动作 / 收集累加倍率，严重失误（撞致命障）清零
- **计分**：距离 × 实时倍率；本地最佳记录
- **死亡 / 重开**：触碰致命障碍即终局，一键重开

### Dynamics（机制涌现的玩法）
- **风险决策循环**：玩家在"稳过"与"贴脸蹭分"间持续权衡；连击越高越不愿停 → 紧张感与心流来源
- **节奏预判**：速度递增 ↔ 二段跳 / 过弯窗口管理，要求提前读图而非纯反应
- **轨道空间利用**：三轨让横向空间可被主动利用（左右规避 vs 贴脸近失），玩家自发寻找低险高回报的轨道走位
- **动作密度压力**：连击清零威胁推动玩家"不能停"，维持高速代入感
- **过弯张力**：转角强制锁中轨 + 视角旋转制造"被迫专注"段落，过弯后立即恢复操控形成节奏起伏

### Aesthetics（8 类趣味取向 · 主打标注）
| 取向 | 主打？ | 理由 |
|---|---|---|
| **Challenge（挑战）** | ★ 主打 | 核心乐趣 = 技巧精通（切轨时机 / 二段跳 / 过弯 / 贴脸近失）与刷新个人最佳 |
| **Sensation（感官）** | ★ 次主打 | 废土视觉（暗调 + 应急光 / 余烬）+ 音效 + 残影 + 过弯视角旋转是网页 / 小程序即点即玩的第一吸引力，强化打击感 |
| **Submission（消磨 / 沉浸）** | ◐ 轻度 | 一局接一局的"再来一次"循环 |
| **Discovery（探索）** | ◐ 弱 | 近失高分区 / 解锁内容作轻量钩子 |
| Fantasy / Narrative / Fellowship / Expression | ✕ 不主打 | 保持 lean，不做剧情 / 社交 / 建造，避免支柱漂移 |

## 9. 玩家心理学
### 自我决定论（SDT）
- **自主 Autonomy**：三轨选择（左 / 中 / 右）、风险偏好、角色 / 皮肤自定义。
- **胜任 Competence**：连击倍率 + 最佳距离给出清晰可量化的精通反馈；难度平滑上升，正向强化。
- **关联 Relatedness**：MVP 弱；核心档经最佳榜 / 分享 / 每日目标提供轻社交，**不做强联机**（契合 Web / 小程序轻量定位）。

### Bartle 玩家类型
- **主打 Achievers（成就型）**：刷距离、破记录、解锁。
- **兼纳 Explorers（探索型）**：发现近失高分区、不同轨道走位的回报差异。
- **不主打 Killers / Socializers**：无 PvP、无强社交系统。

### 心流（Flow）
- **挑战 / 技能曲线**：速度随距离缓增 + 障碍密度缓增，匹配熟练度上升；二段跳 / 过弯在 ~第 3–5 局引入新技巧窗口，避免早期认知过载。
- **沉浸维持**：即时反馈（连击↑、近失特效、音效、过弯视角旋转）保持代入；死亡即重开降低挫败、维持回环。

## 10. 里程碑设定（保留原语义 · 重写为三轨结构）
- **无限距离 + 跨局里程碑奖励**：每 **500m** 触发一次解锁提示（轻量成长节奏）。
- **跨局累计里程碑**（与 combo-scoring §7 同一真值，供解锁 / 称号 / 特效）：
  - 累计距离 `{1000, 5000, 20000} m` → 皮肤解锁
  - 单局最佳 `{250, 500, 1000} m` → 称号
  - 连击峰值 `{20, 40, 80}` → 特效
- 单局时长预期 **30–90s**（死亡即终）；每局结束到下一局开始 < 2s（P3 零等待）。

## 11. 风险与开放问题（待主理人 / 后续阶段拍板）
1. **操作方案（已定）**：三轨单指滑动（左 / 右切轨、上跳、下滑铲、转角锁中轨）；MVP 先验证手感，移动端叠加手势，桌面端方向键等价。
2. **单局目标 / 胜负定义（已定）**：纯无限距离（刷新单局记录）+ 跨局累计里程碑解锁（每 500m 提示），兼顾无限重玩与成长节奏。
3. **变现 / 留存钩子（已定 = 激励视频）**：复活 / 翻倍 / 里程碑三处广告钩子，每日上限 `rvDailyCap=3`（与架构侧 `revive_daily_cap=3` 对齐，按平台政策可配置），Web 走 H5 广告 SDK / 发行平台（工程评估接入）。皮肤仍可用累计补给解锁，无强制付费。详见 core-loop §6.1。
4. **性能预算边界（R4 已回签）**：Godot Web 目标 **60fps@720p（移动端降级 480p）**；`Vmax=13`、`maxLiveObstacles=12`、`spawnLookahead=1.5×屏`、`PPM=50`、首包 `.pck<5MB` 均已由工程回签可达。
5. **跨文档冲突（已解决）**：原 `obstacle-gen` / `combo-scoring` GDD 引用的「蹬墙 / `WALL_KICK` / Wall 障碍」孤儿机制，已由 design-strategist-2-2 从两份 GDD 移除（全仓 design/ grep 验证零残留）；原 Wall 障碍已并入 **Blocker（SWITCH-only 满高障碍）**，由三轨切轨规避，无需蹬墙。三轨动作集（切轨 / 跳 / 滑 / 过弯）已完整承载全部玩法，跨文档已无分歧。
6. **D2 决策标签（主理人已裁定）**：原锁定决策 D2 字面为「2D 横向卷轴 + 2.5D 视差」，与本次重构的「2.5D 伪3D 三轨背后视角」语义不一致；**主理人已裁定：D2 被《神庙逃亡》式三轨选择明确取代，以新三轨呈现为准，原 D2 文本标注『已演进』**（本文件以新玩法呈现为准）。

*设计红线自检：无主导策略（风险 / 安全路线并存且有真实代价）、无经济失衡（MVP 无付费，核心档仅轻量激励视频）、无早期认知过载（动作分层引入）、无支柱漂移（不引入剧情系统 / 社交；丧尸末日仅为视觉与叙事包装，非剧情系统）。*
