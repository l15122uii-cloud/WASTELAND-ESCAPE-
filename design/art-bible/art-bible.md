# 美术圣经 (Art Bible) — 《WASTELAND ESCAPE / 废土逃生》三轨背后视角跑酷

> Phase 1 概念孵化 · 视觉身份交付物（lean）· Phase 3 修订：黄昏/夜晚霓虹夜跑 · Phase 4 修订：末日丧尸 / 废土逃生 · Phase 5 修订：2.5D 伪3D 三轨背后视角（神庙逃亡式）
> 引擎 Godot 4（gl_compatibility / WebGL2）· 目标平台 Web / HTML5 · 轻量优先

---

## 0. 技术底座约束（贯穿全文）
- **形态**：**2.5D 伪3D 三轨背后视角（第三人称追尾）**。玩家居屏幕下方偏中、向纵深（**+z**）自动奔跑；三条并行轨道沿 **x** 分置（左 / 中 / 右），由左右滑手势切轨；赛道周期性**过弯**（转角处锁定中轨）。视觉纵深由**透视摄像机 + 指数雾 + 低多边形几何**卖出，而非原 2D 横版多层视差。
  - **渲染方式**：Godot 4 `Camera3D`（透视）置于玩家身后上方做追尾；材质以**廉价 unlit / 顶点色 / 1–2 阶 toon** 为主，无 PBR、无 normal map、无实时阴影（玩家脚下仅 blob shadow / 投影贴片）。理由：三轨纵深与过弯旋转天然需要 3D 透视与相机 yaw；低多边形 + 顶点色在 WebGL2 下仍最省（无贴图负担），契合"轻量优先 + 即点即玩"。
- **性能红线（沿用并适配三轨）**：单屏 **draw call ≤ 50**（低多边形 + 几何 atlas/合并 + GPU instancing 复用轨道瓦片与丧尸模型）；环境/轨道贴图 ≤ 256px 且 atlas 合并，优先顶点色；禁用实时阴影；粒子池化、同屏 ≤ 120（与 GDD R4 一致）。**过弯旋转 = 相机 yaw（仅改相机矩阵），不重建几何 / 不堆叠后处理**，以免突破 draw call 与帧预算。
- **包体目标**：首屏资源压缩后 **< 5MB**；材质以顶点色 / 纯色块为主，确需贴图则 ≤ 256px、atlas 合并、压缩（`.webp` / `.ctex`）；纯色 / 顶点色优先于位图。

## 1. 概述与基调 (Mood / Tonality)
**一句话定位**：废土黄昏下的幸存者逃亡——干净、克制、节奏凌厉的轻量街机跑酷；在残破城市的尘霾与裂墙间，你以第三人称追尾视角沿三条轨道向纵深疾奔，追逐速度与生机。

**基调**：压抑但不绝望、动能、克制的高级感（末日废土）。不纯暗黑、不血腥堆砌；用"脏橙落日最后一缕余温"对冲逃亡的紧张，让失败也保有"再来一次"的轻盈重试欲。三轨纵深 + 周期过弯带来"向前逃、向深处钻"的沉浸压迫，而非横向卷轴的侧观距离感。

## 3. 色彩系统 (Color)
**原则**：高对比、语义固定、可读性优先（障碍必须瞬间可辨）；**三轨区分不单纯依赖颜色**（见第 4 节 / accessibility 三轨可读性）。

| 角色 | 色值 | 用途 / 心理 |
|---|---|---|
| 主色·环境 | `#2B3A55` 深暮蓝 | 残破建筑、裂墙结构、轨道基底；冷静基底衬托暖色主角 |
| 辅色·天空 | `#E08A4A` → `#4A5360` 脏橙落日→灰蓝硝烟 | 废土黄昏 / 烟霾尘雾，末日氛围 |
| 强调·玩家(幸存者) | `#FF6B5E` 珊瑚红橙 | 唯一最高对比暖色，**绝不**用于危险；玩家辉光色 |
| 强调·收集(补给/弹药) | `#FFD23F` 金 | 奖励物，高饱和、与危险色明确区分 |
| 危险·障碍(丧尸) | `#FF3B5C` 警示红 | **仅用于危险**，玩家一学即懂 |
| UI / 能量 | `#36E2C2` 薄荷青 | HUD、能量条、按钮 hover、轨道指示 |
| 连击特效(急救包/连击) | `#B66BFF` 紫 | 连击数、拖尾、演出高光 |

- **色彩心理**：脏橙落日=余温/生机；珊瑚主角在冷调尘霾里靠**加法辉光 / 亮色 rim**"跳"出来；警示红专司危险（丧尸 / 障碍）。
- **可读性 / 可访问性**：避免红绿作为唯一区分——危险除红色外再加**形状 + 脉动**提示（色盲友好；脉动须**慢速柔和不频闪**，防光敏，详见 `accessibility.md`）。玩家(珊瑚 `#FF6B5E`) vs 环境(暮蓝 `#2B3A55`) 对比度 ≥ 4.5:1；障碍(红) vs 路径(蓝) 强对比。
- **R5 暗调分辨（三轨适配·重要）**：尘霾 / 暗调下玩家珊瑚与危险红同属红系、易混淆，且三轨视角下玩家位于屏幕下方、丧尸分布前方多轨，混叠风险更高。对策——(a) **玩家（追尾视角）**：加**加法辉光 / 亮色 rim + 脚下光环**，使其明显"被照亮的主角"，并置于固定屏幕区（下中）便于定位；(b) **危险**：保持**锐角 + 脉动描边**、核心压暗、不抢光，同一障碍在三条轨上用**相同危险语言**（形状 + 脉动），避免靠颜色与位置误判；(c) 用**形状差**（圆润玩家 vs 锐角丧尸）与**动画差**（危险脉动、玩家常亮）拉开感知距离，而非依赖色相。
- **三轨可读性（不靠颜色 alone）**：三条轨道的区分**不以颜色为唯一手段**——轨道边界用**发光描边条 + 地面箭头/雪佛龙纹理**标示，并结合**位置（左/中/右固定屏幕区）**与**图标/符号**（如中轨高亮、切轨方向箭头）冗余表达，照顾色盲与低视力（详见 `accessibility.md` 三档）。

## 4. 形状与线条语言 (Shape & Line)
- **主角(幸存者，追尾视角)**：圆润胶囊剪影（从背后看为圆润肩背 + 兜帽轮廓），头身比略大（俏皮不幼态）；末世装束（兜帽 / 护目镜 / 背包 / 绑带）靠轮廓与顶点色表达；**圆润以利高速辨识**。玩家固定出现在屏幕下中区域，加一道细 rim light + 脚下光环提神。
- **三轨轨道**：三条并行轨道由**几何嵌条 / 发光边界**分隔（左/中/右），边界用薄荷青（`#36E2C2`）或环境色描边发光；**地面纹理（雪佛龙箭头 / 方向纹）**指示前进与切轨方向，过弯前地面出现转向箭头提示。轨道采用干净几何体、倒角块面（低多边形友好），叠加残破细节（裂痕、缺口、倾斜）。
- **线条**：极少黑描边，靠明度 / 色相分离；必要时用 ≤ 2px 同色系 rim。
- **障碍(丧尸) vs 角色**：障碍用**锐角 / 三角形**（尖刺、路障、扑出的丧尸爪），与圆润主角形成形状对比；丧尸以**风格化几何剪影**表现，**去写实血腥**。三条轨上的同类危险用**统一形状语言**，玩家靠形状而非颜色即可判断"哪一轨有危险"。

## 5. 材质与表面 (Material / Surface)
- **取向**：纯平涂 / 1–2 阶 toon 分色，无 PBR；表面哑光、轻微风格化；材质以**顶点色 / 纯色块**为主。
- 主角加一道细 rim light 提神；环境靠剪影与色块，废墟用低饱和、做旧哑光。
- **贴图策略**：优先顶点色 / 纯色块 / 渐变贴图；确需贴图则 ≤ 256px、atlas 合并、压缩（`.webp` / `.ctex`）；不用 normal map。低多边形网格 + 顶点色使**包体远小于大张 2D 视差 atlas**，利于 < 5MB 红线。
- 可选：极淡颗粒 / 暗角 / **尘霾 haze**（cheap 后处理）增强氛围；过弯过渡用暗角/运动模糊（见第 9 节），不堆叠重后处理。

## 6. 光照与氛围 (Lighting / Mood)
- **追尾光照**：废土黄昏 / 尘霾光（右上脏橙落日余光 + 冷调硝烟补光），尘霾主导；**无实时阴影**（玩家脚下廉价 blob shadow 足矣）。
- **纵深靠雾 + 透视卖出**：用 `WorldEnvironment` **指数雾（exponential fog）** + 渐变天空做 depth fade，近大远小、远轨丧尸随雾衰减隐没——**零几何成本**卖出三轨纵深与速度；尘霾层兼作速度与"末日压迫感"载体。雾距离需调校，使**危险障碍在最远可反应距离内清晰可辨**（满足 GDD 反应窗口），不可因雾过浓牺牲可读性。
- **过弯时的光照/画面处理**：周期过弯时相机 yaw 旋转，画面用**运动模糊（方向性、轻量）或暗角渐变过渡**衔接转角，**避免频闪 / 硬切**；暗角轻度、缓入缓出（详见第 9 节与 accessibility 防眩晕）。Godot：`WorldEnvironment`（fog + gradient sky）保持 cheap；后处理仅暗角 / 轻微 bloom（设置可关）。

## 7. 角色与生物 (Character / Biome)
- **主角(幸存者 Runner，追尾视角)**：灵巧逃亡者，圆润剪影 + 末世装束（兜帽 / 护目镜 / 背包），表情化（可在镜头轻微侧转时露出）。状态：跑、跳、二段跳(空中)、滑铲(蹲)、过弯锁中轨。固定位于屏幕下中，靠辉光/光环定位。
- **障碍（危险红，形状各异，去写实血腥）**，按**三轨纵深**布置：
  - 丧尸群 Horde（跳 / 滑）— 锐角红边扑出剪影，可出现在左/中/右任意轨，前方多排纵深排布（近大远小 + 雾衰减）
  - 尖刺 / 钢筋 Spike — 三角形警示红
  - 悬空横杆 / 断梁 Overhead（滑铲）— 红横杆，玩家需滑铲穿过
  - 缺口 Gap（跳跃）— 地面断口，需跳越
  - 裂墙 / 坍塌 Blocker（满高残破建筑）— 垂直暮蓝残破面，**满高障碍，靠切轨（SWITCH）规避**
  - **三轨布置原则**：每条障碍明确占据一条或两条轨（留至少一条安全轨），纵深方向上按 **near→far** 排列，远障随雾隐没；危险表达统一（形状 + 脉动），玩家在追尾视角下向前看即可预判"哪条轨前方有险"。
  - 表现方式：风格化几何剪影 + 缓速脉动红描边，**非写实肉体**。
- **收集物**：补给 / 弹药（金色旋转盘）、急救包 / 连击星（紫），置于某条轨上，随纵深缩放。
- **装饰 / 生物**：视差废墟城市剪影（远景低多边形天际线）、远处飘散硝烟、轻尘霾；可选"追逐阴影丧尸潮"作软性威胁（纯氛围，不写实）。

## 8. UI 视觉语言 (UI Visual)
与游戏世界统一，叠加于 3D 之上（HUD 为 2D 覆盖层）：
- **HUD**：距离(上)、分数 / 连击(角)、能量条；面板用与平台一致的**圆角块面**，薄荷青强调。
- **三轨指示**：屏幕下方以三枚圆点 / 轨道高亮标示当前所在轨（位置 + 图标冗余，非纯色）；切轨时目标轨薄荷青高亮脉冲。
- **字体**：圆角几何无衬线（Nunito 类），粗体，保证小屏可读。
- **按钮**：胶囊形，珊瑚主 / 暮蓝次，薄荷 hover。
- **菜单**：废土黄昏 / 硝烟渐变背景上的轻量玻璃拟态面板（暗底 + 做旧描边）。
- **图标**：同形状语言（圆润几何 + 末世符号），统一描边权重。
- **连击计量**：随连击增长、紫色辉光。

## 9. 动效与演出 (Motion / Juice)
- **相机（追尾）**：`Camera3D` 置于玩家身后上方，跟随带前向 lead、平滑 lerp；切轨时相机轻微横移/跟拍，不甩镜。
- **玩家**：落地 squash & stretch；起跳前 anticipate 前倾；二段跳加**残影拖尾**。
- **切轨（左右滑）**：玩家横向 lerp 到目标轨 + 地面箭头闪示方向，轨道边界光带脉冲。
- **受击**：小幅屏震 + 红色暗角闪（**慢速柔光、非频闪**，防光敏）+ 0.1s 慢动作；粒子爆裂（**尘土而非血**）。
- **收集**：弹跳放大 + 金光 sparkle；连击数字上浮、紫拖尾。
- **速度感**：随距离轻微 dolly / FOV 增 + 速度线 + 尘霾拉丝 + 近大远小纵深滚动。
- **过弯旋转（关键）**：周期过弯时相机 **yaw 旋转**到新方向，**限制角速度、缓入缓出（ease）**，并用**运动模糊（轻量方向性）或暗角渐变**做过渡；**严禁频闪 / 硬切换 / 强闪**；过弯前地面转向箭头预告。角速度与过渡时长须满足 accessibility 防眩晕（角速度上限 + 过渡缓冲，详见 accessibility.md）。
- **粒子**：GPU 池化、同屏 ≤ 120；落地尘土、速度尘霾线、补给闪光（**避开写实血液表现**）。
