# 可访问性分级 (Accessibility Tiers) — 《WASTELAND ESCAPE / 废土逃生》三轨背后视角

> Phase 3 美术 / UX 可访问性交付 · 与「单指即达」支柱对齐 · Phase 4 修订：末日丧尸 / 废土逃生补充（丧尸去血腥、防光敏）· Phase 5 修订：三轨背后视角新增「三轨可读性」「过弯旋转防眩晕」
> 引擎 Godot 4 · 目标平台 Web / HTML5

---

## 0. 设计原则
- **单指即达**：核心循环（跳 / 滑铲 / 二段跳 / 切轨 / 收集）全部可由单一触控或单键完成，且菜单、暂停、设置均可单指点达。
- **不靠颜色 alone**：危险 / 收集 / 能量 / **轨道区分**一律用 **形状 + 图标 + 动画 + 位置** 冗余表达（色盲友好，呼应美术圣经第 3、4 节）。
- **表现克制（末日主题基线）**：丧尸 / 危险以**风格化几何剪影 + 缓速红描边**表现，**去写实血腥 / 写实肉体**；受击反馈用**尘土粒子而非血液**（与美术圣经第 7、9 节一致）。
- **三轨可读性（三轨视角基线，Phase 5 新增）**：三条轨道的区分**不以颜色为唯一手段**——轨道边界发光描边 + 地面箭头/雪佛龙纹理 + 固定屏幕位置（左/中/右）+ 三轨指示图标，**形状/位置/图标冗余**；色盲与低视力玩家凭位置与图标即可判断当前轨与切轨方向，无需依赖颜色。
- **过弯不眩晕（三轨视角基线，Phase 5 新增）**：周期过弯的旋转**限制相机角速度、缓入缓出**，用运动模糊或暗角**柔和过渡**，**严禁频闪 / 硬切 / 强闪**；Reduce Motion 下可降级为瞬时对齐或弱化旋转。
- **分级递进**：Basic 保证可玩，Standard 提供常用辅助，Comprehensive 覆盖特殊需求；各档特性**可自由叠加组合**。

## 1. 三档分级与特性矩阵

| 特性 | Basic（基础可达） | Standard（标准可达） | Comprehensive（全面可达） |
|---|---|---|---|
| **单指核心操作** | ✅ 跳/滑/二段跳/切轨 全单指触发 | ✅ 同 Basic | ✅ 同 Basic + 单手全功能（菜单/暂停/设置） |
| **语义固定配色 + 形状冗余** | ✅ 危险=锐角+脉动，不靠颜色 alone | ✅ 同 Basic | ✅ 同 Basic |
| **三轨可读性（形状/位置/图标辅助）** | ✅ 轨道边界发光+地面箭头+位置固定，不靠颜色 alone | ✅ 同 Basic + 三轨指示图标/高亮 | ✅ 同 Basic，可叠加高对比 |
| **过弯旋转防眩晕** | ✅ 角速度限频、缓入缓出、无频闪/硬切 | ✅ 同 Basic | ✅ 可降为瞬时对齐/弱化旋转（Reduce Motion） |
| **默认对比度** | ✅ 正文/UI ≥ 4.5:1 | ✅ 同 Basic | ✅ 同 Basic |
| **可调文本大小** | ✅ 游戏内 ±1 档 | ✅ 多档 + 系统同步 | ✅ 多档 + 持久化 |
| **屏幕震动可关** | ✅ 设置项 | ✅ 同 Basic | ✅ 同 Basic |
| **闪烁减弱（防光敏）** | ✅ 受击红闪可弱化（慢速柔光、非频闪） | ✅ 同 Basic | ✅ 照片敏感安全模式（禁用频闪/强闪） |
| **丧尸/危险去写实血腥** | ✅ 风格化几何剪影，无写实肉体/血液 | ✅ 同 Basic | ✅ 同 Basic |
| **危险脉动限频（防光敏）** | ✅ 脉动慢速柔和、不频闪 | ✅ 同 Basic | ✅ 照片敏感模式下脉动转静态描边 |
| **显式色盲模式** | — | ✅ 红/绿/蓝盲预设，危险/收集/能量色相重映射 + 图标区分 | ✅ 同 Standard，可与高对比叠加 |
| **减速 / 自动滑铲辅助** | — | ✅ Assist 档：速度-15%、自动滑铲、判定窗口放宽 | ✅ 可调强度档位 |
| **高对比模式** | — | ✅ HUD/障碍描边强化、暗角减弱 | ✅ 可与色盲模式组合 |
| **字体可读性增强** | — | ✅ 圆角无衬线粗体默认、可读字号下限、可选易读字体 | ✅ 同 Standard |
| **音效可视化** | — | ✅ 收集/危险用屏幕边缘色脉冲 + 图标提示 | ✅ 全事件覆盖 |
| **输入缓冲 / 容错** | — | ✅ 跳跃缓冲 + 土狼时间 + 切轨缓冲 | ✅ 同 Standard |
| **按键 / 触控重映射** | — | — | ✅ 允许动作映射到不同区域 / 外接手柄 |
| **字幕 / 语音提示** | — | — | ✅ 连击、能量、危险临近、过弯预告均有文字/符号提示 |
| **减弱运动 (Reduce Motion)** | — | — | ✅ 镜头 kick / 视差加速 / 速度线 / 过弯旋转降级为静态提示 |
| **可持久化偏好（首启向导）** | — | — | ✅ 记忆设置、跨会话保留 |

## 2. 分级结论与默认建议
- **出厂默认 = Standard**：在 Web 即点即玩场景下，Standard 以极小成本覆盖大多数玩家（色盲、反应慢、小屏可读、光敏、三轨辨识、过弯眩晕），且不破坏「单指即达」核心体验。三轨可读性（轨道边界/箭头/图标）与过弯防眩晕（角速度限频/缓动）在 Basic 即生效（属美术/视角基线，不随档位关闭）。
- **Basic** 作为最低保障基线，确保任何设备/网络下都能开箱即玩；丧尸去血腥、脉动限频、三轨可读、过弯防眩晕在 Basic 即生效（属美术/视角基线，不随档位关闭）。
- **Comprehensive** 面向有特殊需求的玩家，所有开关**默认关闭**、按需开启、可叠加，**不影响普通玩家手感**。
- 美术侧需保证：色盲模式与 R5 暗调分辨（玩家珊瑚辉光 vs 危险锐角脉动）在任意档位下都生效；**照片敏感安全模式**开启时，危险"脉动"由动态转为静态描边，受击红闪改为柔和淡入；**三轨区分**与**过弯旋转**在所有档位均满足可读性/防眩晕基线。

## 3. 与美术圣经 / UX 的衔接
- 本分级为**可访问性基线**；UX 规格（由 design-strategist 产出）**须引用本分级**，明确每个菜单/提示所属档位与默认值。
- 末日主题下，丧尸/危险的「形状 + 动画」冗余表达与**去血腥化**由美术圣经第 4、7、9 节落地；三轨可读性由美术圣经第 4 节（轨道边界/箭头/位置）与本节共同定义；过弯防眩晕由美术圣经第 6、9 节（相机 yaw 限频、运动模糊/暗角过渡）与本文件共同约束。本文件只定义「必须有」的层级。
- 验收见第 4 节，供 QA / 工程对照。

## 4. 验收建议（给 QA / 工程）
- **Basic**：单指可完成一局；危险（丧尸）在无颜色提示下仍可凭形状辨识；震动/闪烁开关生效；丧尸为风格化剪影、无写实血肉；受击为尘土非血；**三条轨道可凭边界发光 + 地面箭头 + 固定位置分辨（不靠颜色）；过弯旋转角速度受限、缓动、无频闪/硬切**。
- **Standard**：开启色盲模式后，危险/收集/能量三者色相与图标均区分明显；Assist 档下速度-15% 且自动滑铲可用；高对比模式 HUD 描边可见；危险脉动为慢速柔光不频闪；三轨指示图标/高亮可见；过弯有运动模糊/暗角柔和过渡。
- **Comprehensive**：重映射后单手可玩；照片敏感模式无频闪（脉动转静态描边、受击红闪柔化）；Reduce Motion 下镜头/视差/过弯旋转降级；过弯可降为瞬时对齐；设置跨会话保留。
