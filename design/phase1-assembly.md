# Phase 1 概念孵化 · 汇编交付（主理人：游承峰）

> 项目：《WASTELAND ESCAPE / 废土逃生》（原立项名《NEON RUN / 霓虹跑酷》，已于 Phase 1→三轨重构演进）— Godot · Web/HTML5 · lean 评审
> 阶段结论：Phase 1 交付完成，可进入 Phase 2（系统设计）前需先拍板 4 项决策。
> ⚠️ 演进注记：本案已从「2D 横版 + 2.5D 视差 单线跑酷」演进为「2.5D 伪3D 三轨背后视角（类《神庙逃亡》）」；原 D2 决策文本以「已演进」为准，详见核心循环 GDD 与各 GDD §11。

## 一、概念结论（来自 design-strategist 文策渊）

**一句话概念**：为碎片时间网页玩家打造的极简霓虹跑酷——单手单键即在自动前进的都市中跳跃/滑铲/二段跳/蹬墙，在躲障与贴脸连击里刷新距离记录。**低门槛上手、高深度精通、30 秒一局、强烈再来一次欲。**

**三根设计支柱**
- **P1 一指即达的纯粹操作**：复杂度来自动作组合与时机，不新增"必须学才能玩"的输入。
- **P2 风险即奖励**：贴脸/近失高回报，安全路线可行但低效；连击清零威胁驱动动作密度，单次失误不直接致死。
- **P3 30 秒一局的成长感**：重开零等待、每局可见成长、难度平滑、早期不劝退。

**MDA 主打**：Challenge（挑战精通）+ Sensation（感官打击），兼纳 Discovery（蹬墙捷径/近失高分）。服务 Achiever / Explorer，不做 PvP/社交/剧情。

**核心循环（动词优先）**：跑 → 跳/滑/蹬 → 躲/收 → 连/刷 → 重开（单局 30–90s，重开 < 2s）。

**范围分层**：MVP 仅 跳+滑+单障碍+金币+计分+一键重开；核心档加 二段跳/蹬墙/多障碍/连击倍率/皮肤解锁/轻量留存；延展档含异步排行/社区路线/无障碍。

## 二、美术方向（来自 art-director 林绘澄）

**形态（已建议）**：2D 横向卷轴 + 多层视差（2.5D），扁平/低多边形风格化 → Godot 2D 在 Web 端性能与包体最优。

**视觉基调**：霓虹黎明下的都市飞跑——干净、明亮、节奏凌厉，乐观克制的高级感。

**语义固定配色**（可读性核心）
| 角色 | 色值 | 用途 |
|---|---|---|
| 玩家 | `#FF6B5E` 珊瑚 | 唯一最高对比暖色，绝不用于危险 |
| 危险 | `#FF3B5C` 警示红 | 仅危险，加形状+脉动（色盲友好） |
| 收集 | `#FFD23F` 金 | 奖励物 |
| UI/能量 | `#36E2C2` 薄荷青 | HUD/按钮 |
| 连击 | `#B66BFF` 紫 | 连击特效 |
| 环境 | `#2B3A55` 深暮蓝 | 结构基底 |

**性能红线**（美术侧建议，待工程回签）：单屏 draw call ≤ 50；贴图 ≤256px 走 atlas；无实时阴影（仅 blob shadow）；同屏粒子 ≤120；首屏 <5MB。

## 三、一致性核对（主理人）

### ✅ 已对齐（无需再议）
1. **低多边形 / 极简几何** — 双方一致，契合 Web 轻量。
2. **动态速度线 / 运动残影** — 双方一致，强化 Sensation。
3. **高对比可读 + 强轮廓双编码** — 双方一致，危险用"形状+亮度"而非纯色，色盲友好。
4. **语义固定配色逻辑** — 美术已落地为具体色值与用途，与策划"不靠纯色彩区分危险"一致。

### ⚠️ 待拍板分歧 1：视觉基调（夜 vs 黎明）
- 策划锚点写的是 **「霓虹都市夜跑」**（暗背景+高对比霓虹，靠暗底衬亮色保证可读）。
- 美术落地为 **「霓虹黎明」**（明亮暖桃↔青蓝渐变，靠语义固定色+形状保证可读，且"不暗黑"）。
- 二者美学取向明显不同（暗黑赛博 vs 明亮乐观），但可读性目标一致。**这是唯一需要你定夺的调性分歧。**

### ⚠️ 待拍板分歧 2：形态 2D vs 3D
- 美术推荐 2D 横向卷轴+2.5D 视差（Web 最优）；备选 3D 低多边形（Subway 式三轨），但包体/性能预算需重算。**建议先确认形态再进 Phase 2。**

### 👀 观察项（非阻塞，留待 Phase 2/3）
- 玩家色 `#FF6B5E` 与危险色 `#FF3B5C` 同属红系，色相接近。美术已用"形状+脉动"兜底，但 Phase 2/3 验证时需注意二者在实景中的可分辨度，必要时拉大明度差。

## 六、用户拍板决策（Phase 1 → Phase 2 交接）
| # | 决策项 | 结论 |
|---|---|---|
| D1 | 视觉基调 | **黄昏/夜晚**（采纳偏暗调性，回归策划原「霓虹夜跑」方向；美术圣经需将「霓虹黎明」修订为黄昏/夜晚基调） |
| D2 | 形态 | **2D 横向卷轴 + 2.5D 多层视差**（确认采用，Godot 2D Web 最优） |
| D3 | 操作 | **触屏滑动**（单指手势：上滑跳 / 下滑滑铲 / 贴墙蹬；桌面端映射键盘） |
| D4 | 单局目标 | **单局纯无限距离 + 全局里程碑奖励**（单局刷新距离，跨局里程碑解锁） |

*D1 触发美术圣经修订（美术需在后续阶段将明亮黎明基调改为黄昏/夜晚）；D3 改写 P1 单键假设为单指滑动，仍满足「一指即达」支柱；D4 影响连击计分与进度的 GDD 设计。*
