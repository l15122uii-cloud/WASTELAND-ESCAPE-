# UX 规格文档 · 《WASTELAND ESCAPE / 废土逃生》

> 阶段：Phase 4 预制作 ｜ 角色：design-strategist-4（文策渊）｜ 评审强度：lean
> 引擎：Godot 4（gl_compatibility / WebGL2）｜ 平台：Web / HTML5 + TapTap + 微信/抖音小程序（H5 容器）
> 引用文档：game-concept.md ｜ core-loop.md（§2.1/§3/§6.1）｜ combo-scoring.md（§2.1/§4/§7）｜ obstacle-gen.md（§2.5）｜ art-bible.md（§3/§4/§8/§9）｜ accessibility.md
> 服务支柱：**P1 一指即达** / **P2 风险即奖励** / **P3 30 秒一局成长感**

> 设计红线自检（贯穿全文，不重复标红）：**无主导策略**（安全/贴脸双路线并存且有真实代价）、**无经济失衡**（MVP 无付费；复活仅轻量激励视频，频率上限已锁）、**无早期认知过载**（手势分层教学，MVP 仅 3 手势）、**无支柱漂移**（丧尸末日仅为视觉包装，无剧情/社交系统）。

## 1. 屏幕流（Screen Flow）

### 1.1 顶层状态机（对齐 core-loop §2.1，并 reconciliation 任务参考态）

```
BOOT → MENU → COUNTDOWN → RUNNING [⇄ CORNER 子状态]
                       │ FATAL_HIT（实际碰撞致命障碍）
                       ▼
                    RESULT ──(REVIVE 可选分支/弹层)──▶ RUNNING（复活续跑）
                       │ restart（< 2s）
                       ▼
                   COUNTDOWN → RUNNING
```

- **RUNNING** 是唯一活跃玩法态；**CORNER** 是 RUNNING 内的过弯子状态（core-loop §2.6），不离开 RUNNING。
- **REVIVE 不是独立玩法态**：它是 `RESULT` 态下的一个模态弹层/可选分支（core-loop §6.1）。RESULT 世界已冻结，广告播放不触碰任何活跃物理 tick，无穿隧风险。本规格以此为准，与任务参考态中的「REVIVE」字样一致（仅作弹层呈现）。
- **COUNTDOWN** 在 core-loop §2.1 中定义为独立态（任务参考态未列），本规格保留为「入场读图窗口」（3-2-1-GO，`countdownTime=3.0s`）。是否降级为 RUNNING 子 overlay 待主理人/工程确认（见 §6）。

### 1.2 状态转换与触发条件

| 转换 | 触发条件 | 备注 |
|---|---|---|
| BOOT → MENU | 资源/CDN `.wasm` 缓存加载完成 | 极短（<1s），无用户操作；logo 不闪烁 |
| MENU → COUNTDOWN | 点击「开始 START」 | 单指大热区 |
| COUNTDOWN → RUNNING | 倒计时结束（3-2-1-GO） | 提供读图窗口（P3 零卡顿但不突兀） |
| RUNNING → CORNER | 进入 `turn≠straight` 的 segment（CoreLoop 置 `inCorner=true`） | 锁中轨 + 相机 yaw + 暂停横向输入 |
| CORNER → RUNNING | segment 走完 / 回到 `straight` | 解除锁轨与横向输入暂停 |
| RUNNING → RESULT | `FATAL_HIT`（实际碰撞致命障碍） | 世界冻结，连击随局结束 |
| RESULT → REVIVE(弹层) | 本局 `revive_per_run_max=1` 未用 **且** `revive_daily_cap=3` 未达 | **仅 RESULT 态**可触发（ADR-005） |
| REVIVE → RUNNING | 广告 `onGranted` | 死亡点稍后（`~1s` 无敌）续跑；`combo` 归零、距离保留、清附近障碍 |
| REVIVE → RESULT | 广告 `onDeclined` / 失败 | 不发奖、**不消耗本局机会**（每日上限除外） |
| RESULT → COUNTDOWN | 点击「再来一局 RETRY」 | 对象池复用，< 2s（P3 零等待） |
| RESULT → MENU | 点击「返回菜单」 | 保留 `localStorage` 最佳/里程碑 |
| RUNNING → PAUSE | 点击暂停按钮 **或** 系统 `tab blur` 自动暂停 | 暂停物理 tick，回前台恢复（防"回来即死"） |
| PAUSE → RUNNING | 点击「继续 RESUME」 | — |
| 任意 → MENU | 暂停内「退出 QUIT」/ 设置返回 | — |

## 2. 每屏线框规格（文字描述 + 元素清单 + 布局）

> 所有屏幕的 UI 为叠加于 3D 之上的 2D 覆盖层（art-bible §8）。元素命名与 art-bible §3 配色对齐：薄荷青 `#36E2C2`（HUD/轨道指示/按钮 hover）、珊瑚 `#FF6B5E`（主按钮）、金 `#FFD23F`（收集）、警示红 `#FF3B5C`（危险）、紫 `#B66BFF`（连击）。三轨区分**不靠颜色 alone**（边界发光 + 地面箭头 + 固定位置 + 图标冗余，accessibility §0）。

### 2.1 主菜单 MENU

**背景**：废土黄昏/硝烟渐变 + 轻量玻璃拟态面板（暗底 + 做旧描边，art-bible §8）。
**元素清单**：
1. 标题「WASTELAND ESCAPE / 废土逃生」（顶部）
2. 最佳记录卡：最佳距离 / 最佳分数 / 最佳连击（P3 成长感，`localStorage`）
3. 主按钮「开始 START」（胶囊形，珊瑚主，单指大热区）
4. 次按钮行：「设置 ⚙」（常驻）·「解锁 🔓」（核心档商店，MVP 隐藏）
5. 今日复活余量标签：「复活 x/3 🔥」（薄荷青小字，呼应 revive_daily_cap=3）
6. 三轨 mini 指示（可选装饰，强化三轨心智）

```

│      WASTELAND ESCAPE / 废土逃生      │

│   │ 最佳 距离1234m · 分5678 · 连击40│  │  ← 最佳记录卡 (P3)

### 2.2 游戏内 HUD（RUNNING）

**叠加层**，单指可读、不遮挡赛道纵深视野（art-bible §8）。
**元素清单**：

2. 顶部左：分数 `score` + 实时倍率 `m×x.x`

5. 右上角标：复活余量（今日 `x/3` · 本局 `●`/○）
6. 连击中断提示位（见 §5.1）
7. 过弯锁轨指示位（见 §3.2）

```

### 2.4 结算 RESULT

**世界冻结**（world frozen）。**元素清单**：
1. 标题「逃生结束 / GAME OVER」或「新纪录! NEW BEST 🏆」
2. 本局成绩：距离 / 分数 / 最佳连击
3. 对比最佳：「最佳 {best}」+ 提升/未提升标记
4. 主按钮「再来一局 RETRY」（P3 < 2s）
5. 次按钮「返回菜单 MENU」
6. 复活卡（条件显示，见 §5.2 / core-loop §6.1）
7. 翻倍卡（核心档）：「看广告补给翻倍」

### 2.5 复活确认 REVIVE（RESULT 弹层）

**仅 RESULT 态**，激励视频。叠加于 RESULT 之上。
**元素清单**：
1. 弹层标题「免费复活?」
2. 说明：从死亡点稍后（`~1s` 无敌）续跑 · 连击归零 · 距离保留 · 清附近障碍
3. 主按钮「看视频复活 WATCH AD」（出现条件：本局未用 `revive_per_run_max` **且** 每日未达 `revive_daily_cap`）
4. 次按钮「放弃 DECLINE」（→ 维持 RESULT）
5. 条件不满足时：主按钮替换为原因文案（见 §5.2），不出现广告入口
6. 广告播放：RESULT 已冻结，暂停物理 tick；`onGranted`→RUNNING，`onDeclined`→RESULT（core-loop §6.1）

### 2.7 首次教学 FIRST-RUN TUTORIAL

**非阻塞、可跳过、分层引入**（呼应 P3 不劝退、动作分层，防早期认知过载红线）。
**元素清单**：
1. 首局 COUNTDOWN 后，前 ~3 个障碍前的「手势预告」序列（与障碍触发耦合，临近时高亮对应手势）：
   - 切轨：向左/右滑动的手势动画（hand icon + 滑动路径 + 箭头）+ 文字「左右滑切换轨道」
   - 跳：前方出现 Spike 时高亮「上滑跳跃」
   - 滑：前方出现 Overhead 时高亮「下滑滑铲」
2. 过弯首遇：地面转向箭头 + 文字「前方过弯，横向锁定中轨」
3. 进阶教学（核心档，第 3–5 局后）：二段跳（空中再次上滑）、近失贴脸 `+2`
4. 「跳过教学」按钮（不强制，不阻断物理；可用低密度教学障碍段）

## 3. 输入可发现性（Affordance）

### 3.1 首局手势教学（呼应 §2.7）
- **演示动画**：手指滑动轨迹（hand icon + 滑动路径 + 箭头），与**实际障碍临近**耦合（障碍到来前高亮对应手势），避免孤立教学。
- **三手势基础（MVP）**：左右滑 / 上滑 / 下滑；**二段跳 = 空中再次上滑**（同一手势时序组合，**不新教**新手势，坚守 P1）。
- **渐进披露**：仅教当前需要的手势，不过载（防早期认知过载红线）；核心档技巧（二段跳/近失）延后至熟练期。

### 3.2 过弯锁轨反馈（CORNER，RUNNING 子状态）
进入 CORNER（CoreLoop 置 `inCorner=true`）时，多通道反馈（art-bible §4/§6/§9 + accessibility §0）：
- **视觉**：
  - 弯前 lead（≥ `laneSwitchLead`）地面出现**转向箭头预告**（art-bible §4）。
  - 进入 CORNER：底部三轨指示**仅中轨亮**（两侧灰/暗），提示「横向输入已锁定」。
  - 屏幕边缘轻微薄荷青/暗角渐变（**非频闪**）提示转角。
  - 相机 yaw **缓动旋转**（角速度限频、缓入缓出）。
- **触觉**（haptic，平台支持时）：进入/退出 CORNER 轻震动一下（短促，非连续）。
- **听觉**：转角环境风声变化（可选）。
- **Reduce Motion 降级**：过弯旋转降级为瞬时对齐/弱旋转 + 静态箭头提示（accessibility Comprehensive；Basic/Standard 仍缓动但限频无频闪）。

## 4. 无障碍触达点（呼应 accessibility.md 三档）

> 出厂默认 = **Standard**（accessibility §2）。Basic 为开箱即玩基线（三轨可读性/过弯防眩晕/去血腥/脉动限频在 Basic 即生效，不随档位关闭）。Comprehensive 所有开关默认关闭、按需开启、可叠加、不影响普通玩家手感。

### 4.1 色弱模式（色彩辅助）
- **Standard「色盲模式」**：红/绿/蓝盲预设，危险/收集/能量**色相重映射 + 图标区分**（art-bible §3）。
- **三轨可读性（全档位生效，美术/视角基线）**：轨道边界发光描边 + 地面雪佛龙箭头 + 固定屏幕位置（左/中/右）+ 三轨指示图标——**不靠颜色 alone**（art-bible §3/§4；accessibility §0）。
- **R5 暗调分辨**：玩家珊瑚辉光（rim + 脚下光环）vs 危险锐角脉动——靠**形状/动画差**而非色相（art-bible §3 R5）。
- 危险**双重编码**：形状（锐角）+ 脉动（慢速柔光、限频防光敏），不靠纯色。

### 4.2 Reduce Motion（减弱运动）
- **Comprehensive「Reduce Motion」**：镜头 kick / 视差加速 / 速度线 / 过弯旋转**降级为静态提示**（accessibility §1）。
- 过弯旋转降为瞬时对齐或弱化旋转（缓动保留但幅度降）。
- 受击红闪改为**慢速柔光淡入**（非频闪）；照片敏感安全模式：危险脉动转**静态描边**。
- 屏幕震动可关（Basic）。

### 4.3 单指完整体验核对清单（呼应 accessibility.md §4 验收）
- [ ] 单指完成整局（跳/滑/二段跳/切轨/收集 全单指或单键）
- [ ] 菜单/暂停/设置 全单指点达（大热区，无精确拖拽）
- [ ] 危险可凭形状（锐角 + 脉动）辨识，无颜色也能玩
- [ ] 三条轨道凭 边界发光 + 地面箭头 + 固定位置 + 图标 分辨（不靠颜色）
- [ ] 过弯旋转 角速度限频、缓动、无频闪/硬切
- [ ] 屏幕震动可关（Basic）
- [ ] 受击红闪慢速柔光非频闪；尘土非血（去写实血腥）
- [ ] 色盲模式 危险/收集/能量 三者区分明显
- [ ] Reduce Motion 生效（镜头/视差/速度线/过弯降级）
- [ ] 文字大小 ±档可调（Basic+）
- [ ] 设置跨会话保留（Comprehensive）
- [ ] 照片敏感模式 脉动转静态描边、受击柔化

## 5. 与连击 / 复活系统的 UX 衔接

### 5.1 连击中断提示（combo-scoring §2.1）
- **来源**：`BUILDING → IDLE`（衰减窗口 `T=2.5s` 到期）——**非致死软压力**（与 P2「单次失误不直接致死」一致）。`FATAL_HIT`=死亡，另算，不在此提示内。
- **提示设计**：
  - 角落小字「连击中断 / COMBO LOST」+ 紫色淡出动画（呼应连击紫 `#B66BFF`）。
  - 音效可视化：屏幕边缘色脉冲（Standard 音效可视化），无依赖音频。
  - **不弹窗、不阻断物理、不施压**（P3 轻惩罚）。
- **正向反馈**：连击达里程碑 `{20, 40, 80}`（combo-scoring §7）触发「连击 x20!」特效 + 紫拖尾，强化精通（Achiever 驱动）。
- **实时反馈**：HUD 倍率 `m×x.x` 随衰减可见回落（即时反馈 P3）；`m_max=5.0` 封顶（combo=40）。
- **过弯期间（CORNER）**：仅中轨 `graze`/`flank` 近失，连击逻辑不变，HUD 照常显示。

### 5.2 每日复活上限耗尽文案（revive_daily_cap=3，revive_per_run_max=1）
**判定优先级**（core-loop §6.1）：
1. **本局已复活过**（`rvRevivePerRun` 已用）→ 不再提供复活按钮（复活后本局再死直接终局）。
   文案：`本局已使用复活，结算后可直接重开`
2. **每日上限已用尽**（`rvDailyCap=3`，`revive_count_today` 达 3）→ RESULT 不显示复活按钮或显示灰色不可用。
   文案：`今日免费复活已用完（0/3）— 每天 0 点刷新`
3. **二者皆可用** → 显示「看视频复活」（§2.5）。
- **文案原则**：neutral、不施压、不强制，与 P3 轻惩罚/零等待一致；**不承诺「分享得额外次数」**（未定，标 TODO，见 §6）。
- **翻倍/里程碑**同走 `AdSystem.requestRewarded(reason)`，文案类似「看广告补给翻倍」「看广告领里程碑奖励」。
